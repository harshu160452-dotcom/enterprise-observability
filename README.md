# Enterprise Microservices Observability & DevOps Platform

## Overview
A containerized microservices project with monitoring, centralized logging, distributed tracing, and alerting.

## Application
- User Service
- Order Service
- Payment Service
- Redis
- PostgreSQL

## Observability
- Prometheus and Grafana
- Loki and Alloy
- OpenTelemetry and Tempo
- Alertmanager

## Infrastructure and Deployment
- Docker Compose
- Kubernetes on Amazon EKS
- Terraform
- Argo CD
- GitHub repository

## Status
Local observability stack completed. AWS EKS infrastructure deployed; application deployment and CI/CD integration are in progress.
